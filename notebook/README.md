# 🕵️‍♀️ Fraud Detection for E-Commerce & Banking 💳

Welcome to a real-world machine learning project focused on detecting fraudulent transactions in both e-commerce and bank credit card data.

## 📊 What’s Inside?

- 🧼 **Data Preprocessing** – Clean, explore, and engineer smart features  
- 🤖 **Model Training** – Build and evaluate fraud detection models  
- 🔍 **Explainability** – Use SHAP to interpret predictions and uncover patterns  
- 🌍 **Geolocation** – Map IP addresses to countries for added fraud signals  

## 🔧 Tech Stack

- Python 🐍
- Pandas, Scikit-learn, SHAP
- XGBoost / LightGBM
- Jupyter Notebooks 📓

## 📁 Project Branches

| Branch             | Purpose                         |
|--------------------|----------------------------------|
| `main`             | 🔐 Final stable version           |
| `data-preprocessing` | 🧹 Cleaning, EDA, Feature Eng.   |
| `model-training`   | 🤖 Model building & evaluation    |
| `explainability`   | 📊 SHAP visualizations & analysis |
